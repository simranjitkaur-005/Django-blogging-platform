# Django Blogging Platform

This is a blogging web application built using Django.

## Features
- User registration and login
- Create blog posts
- Edit and delete posts
- View blog details
- Clean UI with HTML and CSS

## Tech Stack
- Python
- Django
- HTML
- CSS
- SQLite

## Project Structure
blogproj/
- manage.py
- core (app)
- templates
- static

## How to Run the Project

1. Clone the repository
2. Install requirements

pip install -r requirements.txt

3. Run migrations

python manage.py migrate

4. Start server

python manage.py runserver

Then open:
http://127.0.0.1:8000/
